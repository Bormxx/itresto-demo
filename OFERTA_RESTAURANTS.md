5.2.1. При использовании онлайн-платежей через НКО ООО "Твои платежи" Платформа удерживает комиссию в размере **0,25-1%** от суммы каждого платежа.

5.2.5. Тип Заведения определяется при регистрации на основании предоставленных документов и не может быть изменён без согласования с Платформой.

5.3.1. Средства зачисляются на расчётный счёт Заведения в соответствии с условиями НКО ООО "Твои платежи".

5.3.2. Стандартный срок зачисления: T+1 или T+2 банковских дня с момента совершения платежа.

**Вариант А: Автоматическая фискализация через ОФД (рекомендуется)**

6.2.1. Заведение может подключить оператора фискальных данных (ОФД) через интеграцию с API НКО ООО "Твои платежи".

6.2.3. Гости видят сообщение:
```
Электронный чек отправлен на вашу почту/телефон
Бумажный чек можно получить у официанта
```

**Вариант Б: Ручная фискализация через собственную ККТ**

6.2.4. Заведение может использовать собственную ККТ, подключённую к другому ОФД.

6.2.5. В этом случае официант Заведения обязан пробить фискальный чек вручную после получения информации об оплате и предоставить его гостю.

6.2.6. Гости видят уведомление:
```
В соответствии с 54-ФЗ чек за оказанные услуги 
предоставляется заведением. Для получения чека 
обратитесь к официанту.
```

- Оранждата:
- Атол Онлайн:
