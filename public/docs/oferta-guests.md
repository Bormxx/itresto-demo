## 3. ПОРЯДОК ИСПОЛЬЗОВАНИЯ ПЛАТФОРМЫ

### 3.1. Просмотр меню

3.1.1. Гость сканирует QR-код, размещённый в заведении, с помощью камеры смартфона.

3.1.2. Гость получает доступ к электронному меню заведения с актуальными ценами, описаниями и фотографиями блюд.

3.1.3. Услуга просмотра меню предоставляется **бесплатно**.

### 3.2. Оформление заказа

3.2.1. Гость выбирает блюда из меню и добавляет их в корзину.

3.2.2. Гость может указать дополнительные параметры заказа (комментарии, пожелания к приготовлению).

3.2.3. Гость проверяет состав заказа и общую сумму.

3.2.4. Гость нажимает кнопку "Оформить заказ" и подтверждает заказ.

3.2.5. Заказ передаётся в заведение для обработки персоналом.

### 3.3. Оплата заказа

3.3.1. Гость может оплатить заказ онлайн через Платформу с помощью банковской карты.

3.3.2. Платежи обрабатываются через сертифицированного платёжного оператора **НКО ООО "Твои платежи"** (YPMN).

3.3.3. Все платёжные данные защищены в соответствии со стандартом **PCI DSS**.

3.3.4. После успешной оплаты Гость получает подтверждение на экране устройства.

3.3.5. Средства зачисляются на счёт заведения (за вычетом комиссий НКО и Платформы).

### 3.4. Получение фискального чека (54-ФЗ)

3.4.1. В соответствии с Федеральным законом №54-ФЗ "О применении контрольно-кассовой техники" заведение обязано предоставить Гостю фискальный чек.

3.4.2. **Вариант А (если заведение подключило ОФД через Платформу):**
```
Электронный чек отправлен на вашу почту/телефон
Бумажный чек также можно получить у официанта
```
Электронный чек приходит автоматически сразу после оплаты на email или телефон, указанный при оплате.

3.4.3. **Вариант Б (если заведение использует собственную ККТ):**
```
В соответствии с 54-ФЗ чек за оказанные услуги 
предоставляется заведением. Для получения чека 
обратитесь к официанту.
```
Официант заведения обязан предоставить бумажный фискальный чек по запросу Гостя.

3.4.4. Ответственность за предоставление фискального чека несёт **заведение**, а не Платформа.

Платформа обрабатывает Ваши персональные данные (при регистрации) для следующих целей:
